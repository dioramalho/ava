## Como executar localmente

1. Entre na pasta do projeto:
   ```bash
   cd portal-aulas-ete
   ```
2. Inicie um servidor estático simples:
   ```bash
   python -m http.server 8000
   ```
3. Abra no navegador:
   - `http://localhost:8000/index.html`
